# Pleural Telemonitoring

Android telemonitoring application for patients
with pleural effusion following thoracentesis.

## Technology Stack
- React Native + Expo + TypeScript
- Laravel REST API
- MySQL
- React + Vite
- Firebase Cloud Messaging
- WhatsApp Business API (planned)
